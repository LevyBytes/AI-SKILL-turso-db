# Token list response fields

Open when constructing or interpreting the nested fields used by the linked Platform API operation. Array-item rows describe one element; a required flag applies within its immediate object. A blank required set in the source is not a guarantee that a response field will always be omitted or present.

## Response: `tokens`

| Field | Type | Required in source | Meaning and constraints |
| --- | --- | --- | --- |
| `name` | string | Not declared | The name given to the API Token. |
| `id` | string | Not declared | The ID generated by Turso for the API Token. |
| `organization` | string | Not declared | The organization slug this token is restricted to. Omitted if the token has access to all organizations. |
| `group` | string | Not declared | The group name this token is pinned to. Present only for group-scoped tokens. |
| `scopes` | string[] | Not declared | The expanded list of scopes granted to this token. Present only for group-scoped tokens. Presets passed at creation time (`read-only`, `full-access`) are stored as the underlying individual scopes and are returned in that form. |
| `created_at` | string | Not declared | The date the token was created, in `YYYY-MM-DD` format. |
