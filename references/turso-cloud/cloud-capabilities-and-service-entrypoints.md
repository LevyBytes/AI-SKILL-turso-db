## Vector Search

Turso Cloud offers both **libSQL** and the **Turso Database** engine. The captured Cloud documentation labels hosted Turso databases early preview; engine maturity and hosted availability are distinct. Check the selected engine before applying libSQL-specific features. Turso Cloud provides a managed SQLite-compatible database platform for workloads ranging from prototypes through production. Built on [libSQL](https://docs.turso.tech/libsql), it combines SQLite-style performance and reliability with managed cloud database scalability and convenience.

### Vector Search

Built-in similarity search supports AI apps and RAG workflows without requiring extensions.

### Replication & Sync

Use Turso Cloud to synchronize devices with one another whenever needed.

### Branching

Create fast isolated Copy-on-Write branches.

### Analytics

Track database usage and performance across your databases.

### Bring-Your-Own-Key Encryption

Protect sensitive data with customer-controlled keys. Each database uses its own key for complete isolation.

### Scoped Access Tokens

Use fine-grained tokens scoped to database, table, action, and expiration. Permissions can be read-only, write, or custom.

### Team Access

Work with team members on databases and control their access permissions.

### Fully Managed

Turso manages infrastructure, scaling, and security for you.

### Backups and Recovery

Recover your database within the retention window available on its plan.

Use the Platform API to manage groups and databases from code.
