# Turso 0.5.0: updated functions and runtime

Open when checking these changes in Turso 0.5.0, released 2026-03-04. These are historical release records, not current API availability guarantees.

[Release history](release-history.md) · [This release](release-0.5.0-index.md)

## Updated

- refactor: move emitter.rs into a dedicated module (Preston Thorpe)
- core/vector: skip simsimd on Windows AArch64 (Marc-André Moreau)
- vdbe no-op updates now take the fast path (Preston Thorpe)
- Keep comparison coercion semantics for BLOB versus no affinity (Kumar Ujjawal)
- Prevent DecrJumpZero panic on non-integer register (Kumar Ujjawal)
- drop `Arc<RwLock<Statement>>` from `Insn::Program` (Pedro Muniz)
- Swap panic! and assert! for turso_macros assertions (Mikaël Francoeur)
- prevent scalar blob into JSONB (김선우)
- refactor: avoid `connection.with_schema` inside the `translate` module (Pedro Muniz)
- Clean up assorted lib.rs code (Pekka Enberg)
- core: Make version functions non-deterministic (ratnesh mishra)
- perf: tune FTS performance (Preston Thorpe)
- Reject reserved JSONB element types (Kumar Ujjawal)
- refactor: make translate functions take `&mut ProgramBuilder` (Pedro Muniz)
- vector8 + vector1bit (Nikita Sivukhin)
- keep executing when IO completes immediately (Nikita Sivukhin)
- adjust is_constant check for `IN` and `emit_no_constant_insn` to prevent VDBE cursor panic (Pedro Muniz)
- Reimplement printf for complete SQLite compatibility (Glauber Costa)
- Pragmas (Glauber Costa)
- make `Numeric` authoritative for number comparisons (Pedro Muniz)
- align determinism behavior with SQLite (Mikaël Francoeur)
- core: database open now runs async (Nikita Sivukhin)
- return NULL from `op_column` when no record exists (Pedro Muniz)
- `strftime` should take input of any kind, not just text (Pedro Muniz)
- `CHAR` should yield `\0` for `NULL` (Pedro Muniz)
- Split Connection away from prepared statement for better caching (Preston Thorpe)
- use HashMap instead of FxHashMap in core (Pedro Muniz)
- retry `TursoRwLock::read` when readers contend (Pedro Muniz)
- remove accesses_db flag (Nikita Sivukhin)
- cleanup/vdbe: remove unused IndexKeyOwned and unused IndexKeyUnpacked::cursor_id (Jussi Saurio)
- Refactor AggContext to flat payload representation (Jussi Saurio)
- Confirm Send + Sync for `ProgramState` and change registers to store `Box<[Register]>` (Pedro Muniz)
- core/vdbe: support leading + sign during numeric string parsing (Pere Diaz Bou)
- core/vdbe: trim return text for integer and float (Pere Diaz Bou)
- Reset ProgramState::once when statement resets (Mikaël Francoeur)
- return blob when blobs are concatenated (Nikita Sivukhin)
- Refactor core/lib.rs Connection impl into a separate file (Preston Thorpe)
- core: prefer fast monotonic time when available (Pekka Enberg)
- core/vdbe: move mutable Program fields into ProgramState (Pere Diaz Bou)
- delete unused lints, variables and functions (Pedro Muniz)

- Optimize VDBE read-path micro-operations (Jussi Saurio)
