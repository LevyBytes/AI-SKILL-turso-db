# Account plans overages and limits

[Context index](installation-organization-and-account-commands.md) · [Setup and preceding context](api-token-list-and-scopes.md) · [Previous phase](organization-members-and-active-selection.md) · [Continue](update-turso-cli-by-platform.md)

## Disable

Disable overages for the currently selected Turso account or organization by running this command:

```
turso plan overages disable

```

 Any overages already incurred will still appear as charges.

## Enable

Enable overages for the currently selected Turso account or organization by running this command:

```
turso plan overages enable

```

## Select

Change your current plan whenever needed with this command:

```
turso plan select

```

 Before upgrading to a paid plan, add credit card details to your account. [Learn more](https://turso.tech/pricing) about pricing.

## Show

Display current plan usage and limits with this command:

```
turso plan show

```

## Upgrade

Upgrade your account to a paid plan at any time with this command:

```
turso plan upgrade

```

 A paid-plan upgrade requires credit card details on your account.
