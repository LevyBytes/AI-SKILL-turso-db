# PHP upstream example routes

[Context index](kotlin-and-php-sdk-workflows.md)

Open the [turso-client-php examples](https://github.com/tursodatabase/turso-client-php/tree/main/examples) when using that native PHP extension. Its `LibSQL` class and setup differ from the Composer `turso/libsql` wrapper.

Open the [upstream example directory](https://github.com/tursodatabase/turso-client-php/tree/main/examples) for complete runnable projects and their version-specific dependencies.

| Entry | Use |
| --- | --- |
| [sqld-offline](https://github.com/tursodatabase/turso-client-php/tree/main/examples/sqld-offline) | Offline server example |
| [local.php](https://github.com/tursodatabase/turso-client-php/tree/main/examples/local.php) | Local database |
| [memory.php](https://github.com/tursodatabase/turso-client-php/tree/main/examples/memory.php) | In-memory database |
| [offline-writes.php](https://github.com/tursodatabase/turso-client-php/tree/main/examples/offline-writes.php) | Offline writes |
| [remote-replica.php](https://github.com/tursodatabase/turso-client-php/tree/main/examples/remote-replica.php) | Embedded replica |
| [remote.php](https://github.com/tursodatabase/turso-client-php/tree/main/examples/remote.php) | Remote access |

These are source-project routes. Follow the selected project's own setup and match its SDK version before using the example.
